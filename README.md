# tp_slides_template

A [Télécom Paris](https://en.wikipedia.org/wiki/T%C3%A9l%C3%A9com_Paris) themed touying presentation template. Essentially [gh-minimal-slides](https://github.com/xingjian-zhang/gh-minimal-slides), tweaked for my needs.

Main changes include :

- Different title padding
- Telecom Paris themed, with a Telecom Paris color scheme automatically passed to [lilaq](https://github.com/lilaq-project/lilaq) plots
- Added boxes for math presentation purposes
- Added a bibliography slide
